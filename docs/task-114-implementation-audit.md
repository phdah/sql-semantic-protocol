## Independent soundness review

- **ASOF is not an ordinary `>=` join.** With left times [5,10] and right [4,7], `(l10,r4)` satisfies the predicate but is not selected: `r7` is nearer. Native tie selection, unsupported dialect-specific matching and whether an unmatched ASOF emits a synthetic NULL or no row are not inferred. The finite law now returns no proof when an unmatched left row lacks certified preservation.
- **Correlated LATERAL/APPLY is per-left-row evaluation.** A complete right physical bag is shared, but correlation selects a different matching subbag for each left row. Duplicate right identities fan out; OUTER APPLY missing partners create projected NULL without fabricating a physical NULL-valued right row. Effectful/native table functions remain unsupported.
- **Portable proofs are sufficient realizations, not exhaustive native engine certificates.** Input values and type metadata must meet schema bounds and source constraints. Parser recognition and DuckDB-only execution cannot establish arbitrary vendor tie/session/function laws. All five vendor conditions retain an explicit owner, missing evidence and pending release disposition.
