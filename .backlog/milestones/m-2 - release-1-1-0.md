## Description

Deliver the next backward-compatible feature release of SQL Semantic Protocol.

This milestone starts the post-1.0 roadmap and targets version `1.1.0`. The initial focus is enriching relation metadata beyond column names and datatypes so consumers can reason about structural constraints such as primary keys, unique keys, and foreign keys.

The milestone is intentionally extensible: additional backward-compatible protocol features may be added before release. It is complete when every task assigned to `m-2` is done and Release Please has produced and published version `1.1.0`.
