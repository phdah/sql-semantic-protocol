## Description

Implementation scope completed for the post-1.0 SQL Semantic Protocol milestone.

All 28 assigned tasks (TASK-29 through TASK-56) are marked Done. The milestone delivered canonical relation constraints, source metadata adapters, output-domain and exactness improvements, and differential validation.

The original 1.1.0 target was superseded by **2.0.0** because the protocol change to classify residual causes and normalize boolean predicates is breaking. [Release Please PR #41](https://github.com/phdah/sql-semantic-protocol/pull/41) already prepares version 2.0.0.

**Milestone completion records implementation readiness, not publication.** Git tagging, the GitHub release, and crates.io publication will occur only after the release PR is merged and its workflow succeeds.
